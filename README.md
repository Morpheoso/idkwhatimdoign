# Hello website

A simple, self-contained static website. It uses no JavaScript, third-party libraries, trackers, forms, or external assets.

## Preview in VS Code

Open this folder in VS Code, then open `index.html` in a browser. You can edit the heading and message directly in `index.html`.

## Publish free with GitHub Pages

1. Create or sign in to a GitHub account.
2. Create a **public** repository, for example `my-website`.
3. In VS Code, open this folder, then use **Source Control** to initialize a repository, commit the files, and publish/push it to the new GitHub repository. You can also upload the files through GitHub's website.
4. In the GitHub repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. Wait for the Pages deployment to finish. The Settings → Pages screen will show the published address, usually `https://YOUR-USERNAME.github.io/my-website/`.
7. In **Settings → Pages**, make sure **Enforce HTTPS** is selected when that option appears.

GitHub Pages sites are public on the internet. Do not put passwords, private data, API keys, or other secrets in this folder or repository. HTTPS encrypts visitors' connections, but it does not make published content private.
